3. **Supplement Section R2.2 (Excavation Base Heave Verification — Supersedes Rev.1 §5):**
   * Residual clay plug thickness below subgrade $\text{El. } 726.0$: $t_{\text{plug}} = 726.0 - 720.0 = 6.0\text{ ft}$.
   * Unfactored clay plug weight: $W = 6.0\text{ ft} \times 120\text{ pcf} = 720.0\text{ psf}$; factored resisting weight per `CB-DBM-001 Rev.2` §6.2: $0.9W = 648.0\text{ psf}$.

4. **Supplement Section R2.3 (Layered Effective-Stress + Hydrostatic Lateral Loading Above Subgrade — Supersedes Rev.1 §4.3 & §5):**

#### B. Checks That CANNOT Be Carried Forward as They Stand
1. **Rev.1 Section 3.2 (Undrained Shear Strength $s_u$) & Supplement Section R2.4 (Sheet-Pile Toe Embedment Check — FAILS):**
   * Kesterline uses an unverified undrained shear strength of **$s_u = 1,400\text{ psf}$** carried from Rev.1 §3.2 to compute net passive pressure $p_n = 4s_u - \sigma_{v0} = 4(1,400) - 3,106 = 2,494.0\text{ psf}$, $P_p = 2,494.0 \times 6.5 = 16,211\text{ lb/ft}$ over $D = 6.5\text{ ft}$ (tip $\text{El. } 719.5$, mid-embedment $\text{El. } 722.75$, arm $z_p = 22.75\text{ ft}$), $M_R = 368,800\text{ ft-lb/ft}$, and $FS_{\text{toe}} = 368,800 / 237,293 = 1.55 \ge 1.50$.
   * Against the **logged Geotechnical Report (`KGI-2024-0417 Rev.2` §6.3, p. 13) undrained shear strength $s_u = 900\text{ to } 1,100\text{ psf}$** (mean $1,000\text{ psf}$), the $6.5\text{ ft}$ embedment fails rotational stability across the entire logged strength range:
     * **At logged upper bound ($s_u = 1,100\text{ psf}$):** $p_n = 4(1,100) - 3,106 = 1,294.0\text{ psf}$; $P_p = 1,294.0 \times 6.5 = 8,411.0\text{ lb/ft}$; $M_R = 8,411.0 \times 22.75 = 191,350\text{ ft-lb/ft}$; **$FS_{\text{toe}} = 191,350 / 237,293 = 0.81 < 1.50$ (unstable, $FS < 1.0$)**.
     * **At logged mean ($s_u = 1,000\text{ psf}$):** $p_n = 4(1,000) - 3,106 = 894.0\text{ psf}$; $P_p = 894.0 \times 6.5 = 5,811.0\text{ lb/ft}$; $M_R = 5,811.0 \times 22.75 = 132,200\text{ ft-lb/ft}$; **$FS_{\text{toe}} = 132,200 / 237,293 = 0.56 < 1.50$ (unstable, $FS < 1.0$)**.
     * **At logged lower bound ($s_u = 900\text{ psf}$):** $p_n = 4(900) - 3,106 = 494.0\text{ psf}$; $P_p = 494.0 \times 6.5 = 3,211.0\text{ lb/ft}$; $M_R = 3,211.0 \times 22.75 = 73,050\text{ ft-lb/ft}$; **$FS_{\text{toe}} = 73,050 / 237,293 = 0.31 < 1.50$ (unstable, $FS < 1.0$)**.
   * Because the `CL` clay aquitard ends at $\text{El. } 720.0$ ($6.0\text{ ft}$ below subgrade), the clay layer alone cannot provide sufficient passive toe resistance; the sheet piles must be driven substantially deeper into the underlying dense `SW-GW` sand and gravel aquifer below $\text{El. } 720.0$ and analyzed as a two-layer passive wedge.
2. **Supplement Section R2.5 & Rev.1 Section 10 (Tieback Ground Anchor Design — FAILS on Two Independent Grounds):**
   * **Ground (a) — Bond Zone Lies Entirely Inside the Consolidating `CL` Clay Aquitard, Not in the `SW-GW` Stratum Below $\text{El. } 720.0$:** For anchors installed at waler $\text{El. } 745.5$ at inclination $\theta = 20^\circ$ below horizontal ($\sin 20^\circ = 0.34202$) with $L_{\text{free}} = 25.0\text{ ft}$ and $L_{\text{bond}} = 24.0\text{ ft}$ ($L_{\text{total}} = 49.0\text{ ft}$):
     * Start of bond zone ($25.0\text{ ft}$ along axis): $\text{El. } 745.5 - 25.0 \sin 20^\circ = \text{El. } 745.5 - 8.55 = \mathbf{\text{El. } 736.95\text{ ft}}$.
     * Tip of bond zone ($49.0\text{ ft}$ along axis): $\text{El. } 745.5 - 49.0 \sin 20^\circ = \text{El. } 745.5 - 16.76 = \mathbf{\text{El. } 728.74\text{ ft}}$.
     * Thus, **100% of the $24.0\text{ ft}$ bond zone ($\text{El. } 736.95\text{ to El. } 728.74$) is located inside the normally-consolidated `CL` clay aquitard ($\text{El. } 738.0\text{ to El. } 720.0$), terminating $8.74\text{ ft}$ above the top of the `SW-GW` dense sand and gravel at $\text{El. } 720.0$!** (Reaching $\text{El. } 720.0$ from $\text{El. } 745.5$ at $20^\circ$ would require an unbonded free length of $25.5 / \sin 20^\circ = 74.56\text{ ft}$.) Consequently, Kesterline's application of `FHWA-IF-99-015` Table 4 granular bond stress $\tau_{\text{bond}} = 20\text{ psi}$ ($2,880\text{ psf}$) for dense sand and gravel to claim $Q_{\text{ult}} = 108.6\text{ kips}$ is invalid, and bonding tiebacks within a normally-consolidated clay undergoing primary consolidation violates `FHWA-IF-99-015`.
   * **Ground (b) — Understated Anchor Demand ($T_h$ and $T_{\text{design}}$):** Kesterline computes $T_h = 19,610 - (16,211/1.50) = 19,610 - 10,807 = 8,803\text{ lb/ft}$ ($T_{\text{design}} = 56.2\text{ kips}$ at $6\text{ ft}$ spacing, proof load $74.8\text{ kips}$, lock-off $42.2\text{ kips}$) by crediting the invalid §R2.4 passive force from $s_u = 1,400\text{ psf}$. Using the logged $s_u = 900\text{ to } 1,100\text{ psf}$ ($P_{p,\text{allow}} = P_p / 1.50 = 2,141\text{ to } 5,607\text{ lb/ft}$), required horizontal anchor reaction increases to $T_h = 14,003\text{ to } 17,469\text{ lb/ft}$ and inclined anchor load increases to **$T_{\text{design}} = 89.4\text{ to } 111.5\text{ kips}$** ($100.5\text{ kips}$ at mean $s_u = 1,000\text{ psf}$), yielding $FS_{\text{bond}} = 0.97\text{ to } 1.21 < 2.0$ even if $Q_{\text{ult}}$ were $108.6\text{ kips}$.
3. **Supplement Section R2.6 Flexural Demand ($M_{\max}$), Section R2.7 Wall Deflection ($\delta_{\max}$), and Unupdated Rev.1 Sections 8, 11.3, 11.4, 12, and 13:**
   * In §R2.6, the zero-shear elevation $\text{El. } 733.1$ and maximum bending moment $M_{\max} = 62.4\text{ kip-ft/ft}$ are derived directly from the understated §R2.5 anchor reaction $T_h = 8,803\text{ lb/ft}$ (cumulative active + water load from $\text{El. } 750.0\text{ to El. } 733.1$ is $6,352.4 + 2,471.4 = 8,823.8\text{ lb/ft}$) and invalid §R2.4 toe equilibrium.
   * Similarly, the §R2.7 deflection estimate ($\delta_{\max} = 1.3\text{ in}$) and the unupdated Rev.1 sections retained by Table 1 — Rev.1 §8 (Overturning/Sliding computed for dry excavation and tip $\text{El. } 722.0$), Rev.1 §11.3 (Driveability evaluated for $28\text{ ft}$ sheets in clay at $30\text{ blows/ft}$ rather than driving into $N \ge 50/6\text{ in}$ refusal `SW-GW` gravel below $\text{El. } 720.0$), Rev.1 §11.4 (Waler check), and Rev.1 §13 (Construction Sequence & Drawings still referencing `Submittal 31-DW-A`, tip $\text{El. } 722.0$, and $75\text{ kip}$ lock-off) — cannot be carried forward as they stand.

### 3. Effect of the Excavation Released by This Submittal on Permanent Work Already Built at Block B
Kesterline's design models the $68\text{ ft} \times 44\text{ ft}$ Block B plant-room excavation (`Grids H–L / 3–5`) as an open greenfield cut from working grade $\text{El. } 750.0$ to subgrade $\text{El. } 726.0$, asserting in Rev.1 §4.4 that no permanent structures lie within the $1\text{H}:1\text{V}$ or $1.5H$ ($36\text{ ft}$) influence zone. Against the as-built record, releasing this excavation would severely impact permanent work already constructed at Block B:
1. **Cutting Through and Undermining the As-Built Block A/B Reinforced Concrete Basement Mat (`Sheet S-101 Rev.4`, `Sheet S-201 Rev.4`, `CB-STR-011`, Register Item 050):** The continuous $3.0\text{-ft}$-thick reinforced concrete basement mat ($\text{underside El. } 731.5$, $\text{top El. } 734.5$, over $3\text{-in}$ lean concrete blinding) covers `Grids B–L / 1–5` across both Block A and Block B and was cast on `01/12/2026` (with Level-2 slabs cast `05/18/2026–06/05/2026` and the Level-3 slab cage staged for `07/22/2026`). Because the plant-room footprint (`Grids H–L / 3–5`) lies inside the Block B mat footprint, driving sheets from $\text{El. } 750.0$ and excavating to $\text{El. } 726.0$ would require cutting/demolishing the completed $3.0\text{-ft}$ permanent mat, breaching the below-grade waterproofing and waterstop continuity (`Sheet A-501`, `Detail 4/S-201`), and excavating $5.5\text{ ft}$ below the mat underside ($\text{El. } 731.5\text{ to El. } 726.0$) without underpinning or surcharge design.
2. **Exposing, Unbracing, and Undermining 16 of the 48 As-Built Permanent Driven Pipe Piles (`Pile_Installation_Records_BlockB.xlsx`, `Sheet S-101 Rev.4`, `Detail 2/S-201`):** All 48 permanent $16\text{-in OD} \times 0.500\text{-in}$ wall ASTM A252 Grade 3 closed-end pipe piles (`P-1` to `P-48`, $180\text{ kips}$ service load) were driven from $\text{El. } 750.0$ between `11/06/2025` and `11/21/2025` to tips at $\text{El. } 686.0\text{–}690.0$, with pile cutoffs at $\text{El. } 732.5$ and pile caps from $\text{El. } 732.0\text{ to El. } 734.5$. Sixteen ($16$) of those 48 permanent piles ($4\text{ rows along Grids H, J, K, L} \times 4\text{ piles/row between Grids 3 and 5}$) lie directly inside the plant-room excavation footprint. Excavating to $\text{El. } 726.0$ removes all $12.0\text{ ft}$ of engineered fill ($\text{El. } 750.0\text{–}738.0$, placed `10/06/2025–11/02/2025`) and the upper $12.0\text{ ft}$ of the `CL` clay aquitard ($\text{El. } 738.0\text{–}726.0$) — $24.0\text{ ft}$ of soil confinement — around those 16 piles, cuts $6.5\text{ ft}$ below their cutoff elevation ($\text{El. } 732.5$) and $6.0\text{ ft}$ below their pile cap undersides ($\text{El. } 732.0$), and leaves the upper pile shafts freestanding and laterally unbraced against buckling.
3. **De-Rating Certified Pile Axial Capacity (`CB-GEO-004`):** EOR calculation `CB-GEO-004` certified $Q_{\text{ult}} = 480\text{ kips}$ ($Q_{\text{all}} = 240\text{ kips}$ at $FS = 2.0$ vs. $180\text{ kips}$ service load) by crediting $Q_{s,\text{upper}} = 85\text{ kips}$ of positive shaft resistance between $\text{El. } 750.0$ and $\text{El. } 720.0$ ($10\text{ kips}$ in the $12\text{ ft}$ fill plus $75\text{ kips}$ in the $18\text{ ft}$ clay). Excavating to $\text{El. } 726.0$ physically removes the entire $12\text{ ft}$ fill ($10\text{ kips}$) and $12\text{ ft}$ of the $18\text{ ft}$ clay ($\frac{12}{18} \times 75 = 50\text{ kips}$), directly stripping **$60\text{ kips/pile}$** of upper shaft capacity (and unloading $\sigma'_v$ in the underlying `SW-GW` bearing stratum by $1,857.6\text{ psf}$, reducing $Q_{s,\text{lower}}$), even before accounting for clay consolidation downdrag under Register Item 049.
4. **Tieback Clashes, Lateral Soil Movement ($p\text{-}y$) on Adjacent Piles, and Aquitard Short-Circuiting:** Installing $49\text{+ ft}$ tiebacks at $6\text{ ft}$ centers outward from `Grids H–L / 3–5` risks physical collision with adjacent permanent $16\text{-in}$ pipe piles (`Grid G` and perimeter lines); lateral wall deflection ($\ge 1.3\text{ in}$) imposes unanalyzed lateral displacements on the adjacent pile group and basement mat; and the 16 pile shafts penetrating the residual $6.0\text{ ft}$ clay plug require aquitard collar seals per `KGI-2024-0417 Rev.2` §9.6.
